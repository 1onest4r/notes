directly underneath the AI is the ML which involves creating [[models]], and training on wide variety of data to accomplish certain tasks and predict without having pre-script instructions

ai models can automate decision making but only models that are capable of Machine learning can improve its performance overtime autonomously.

its training can be generally separated in 3 categories
	- "Supervised learning" is a classic example where the data scientist explicitly labels the data set in order for the model to trained.
	- "Unsupervised learning" unlike the example above it doesn't require to know outside validator like *right* or *wrong* thus it doesn't require labeling data set but rather uses cluster to further prediction.
	- "Reinforced learning" is basically rewarding system that trains by reward/penalty
